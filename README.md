# 数字播报工具 · Digital Announcer

把键盘输入的数字、符号和表格内容**读出来**，用于工程量录入时的「听音校对」——边打边听，减少看屏幕、减少录错。

- 版本：**V1.0**
- 平台：Windows 10 / Windows 11（64 位）
- 形态：单文件免安装，离线运行，不联网
- 发布方式：**源码不公开**，提供免费可执行程序（详见[许可](#许可)）

## 功能

| 能力 | 说明 |
|---|---|
| **单键播报** | 每按一个数字/符号立即朗读：零、一、二……加、减、乘、除、点、左括号、右括号、大于、小于、等于；回车读「回车」，退格读「删除」 |
| **批量播报** | 选中表格一块区域，整块播报：第几行、表头、数值 |
| **防抖调节** | 同一按键重复触发的最小间隔（默认 30ms），连打不漏读、不重复读 |
| **语速调节** | 50–300，默认 180 |
| **快捷键自定义** | 四个热键可改、可恢复默认 |
| **托盘常驻** | 关窗即最小化到托盘，单实例运行 |

**适用场景**：造价算量、清单组价、Excel / WPS 表格录入、广联达计价与计量软件录入。

## 默认快捷键

| 快捷键 | 作用 |
|---|---|
| `F12` | 开启 / 暂停播报（会读出「已开启」或「已暂停」） |
| `F10` | 显示 / 隐藏主窗口 |
| `F8` | 手动复制播报：先自己复制好，再按 F8 播报剪贴板内容 |
| `F9` | 自动复制播报：软件模拟 Ctrl+C 复制选中内容，再播报 |

- 批量播报进行中，再按一次 `F9` / `F8` 可中途取消。
- 修改：快捷键设置 → 重新设置 → 按下想要的键（`ESC` 取消捕获）。

### 单键对照表

| 按键 | 读作 | 按键 | 读作 |
|---|---|---|---|
| `0`–`9` | 零 一 二 三 四 五 六 七 八 九 | `Shift`+`0` | 右括号 `)` |
| `+` `-` `*` `/` | 加 减 乘 除 | `Shift`+`9` | 左括号 `(` |
| `.` | 点 | `Shift`+`8` | 乘 `*` |
| `=` | 等于 | `Shift`+`.` | 大于 |
| `Enter` | 回车 | `Shift`+`,` | 小于 |
| `Backspace` | 删除 | 小键盘 | 0–9、`+ - * / .` 同样支持 |

## 批量播报

软件读的是**剪贴板里的表格文本**：列间为制表符（Tab），行间为换行。只要能在目标软件里选中区域并复制，就能播报，空白单元格自动跳过。

**两种用法**

- **F9 自动复制**：选中区域 → 按 `F9` → 自动 `Ctrl+C` → 读取剪贴板 → 播报
- **F8 手动复制**：选中区域 → 右键「复制」（或 `Ctrl+Shift+C` / `Ctrl+C`）→ 按 `F8` → 播报

**播报顺序规则**

- 只有一行：从左到右逐格读
- 只有一列：从上到下逐格读
- 多行多列：先读「第 N 行」，再逐格读「表头，数值」（如「数量，100」）
- 「播报表头」开关关闭时只读数值；表头为空时用「第 N 列」代替

### 广联达各版本怎么用

| 软件 | 推荐方式 |
|---|---|
| 云计价 GCCP 7.0 | 后台模拟按键限制较严，`F9` 常抓不到 → **用 F8**：框选区域 → 右键复制（或 `Ctrl+Shift+C`）→ `F8` |
| 云计价 GCCP 6.0 / 5.0 | 一般可直接 `F9`；提示「自动复制失败」就改用 `F8` |
| 计价 GBQ 4.0 | 多数机器 `F9` 可用；首次无反应先点一下单元格让表格获得焦点，再框选按 `F9` |
| 土建计量 GTJ 2018 / 2021 / 2025 | 表格结构复杂，建议一次只框选一个构件的工程量行，右键复制 → `F8`，并**关掉「播报表头」** |
| Excel / WPS 表格 | `F9`、`F8` 都可以 |

## 常见问题

<details>
<summary><b>Q1 按 F9 提示「自动复制失败」？</b></summary>

目标软件拦截了模拟 `Ctrl+C`（新版广联达常见）。改用 `F8`：手动复制后按 `F8`。
</details>

<details>
<summary><b>Q2 按 F8 提示「剪贴板为空」？</b></summary>

没有复制成功。先选中区域，右键「复制」或按 `Ctrl+Shift+C`（广联达）/ `Ctrl+C`（Excel、WPS），再按 `F8`。
</details>

<details>
<summary><b>Q3 读出来是一整块，不是一格？</b></summary>

广联达复制区域时给的就是整块文本，属正常。只想读一格就只选一格。
</details>

<details>
<summary><b>Q4 完全没有声音？</b></summary>

1. 「语音播报」页是否显示「已暂停」，按 `F12` 恢复
2. 检查系统音量、是否静音
3. 点「试听语音」看有没有声音
4. 系统语音组件（SAPI）被精简的镜像可能不可用，换台机器验证
</details>

<details>
<summary><b>Q5 按键读得慢，或连打时漏读 / 重复读？</b></summary>

调「语速」和「防抖」。防抖调大减少重复，调小减少漏读。
</details>

<details>
<summary><b>Q6 快捷键没反应？</b></summary>

1. 可能被其他软件占用
2. 键盘钩子被杀毒软件拦截，把 exe 加入白名单
3. 到「快捷键设置」里换个键试试
</details>

<details>
<summary><b>Q7 窗口找不到了？</b></summary>

按 `F10`，或点任务栏右下角托盘图标 →「显示设置窗口」。
</details>

<details>
<summary><b>Q8 换电脑、换用户还能用吗？</b></summary>

可以。不绑定机器、不需要注册，配置跟着用户目录走；连软件文件夹一起拷走即可。
</details>

<details>
<summary><b>Q9 配置保存在哪？怎么恢复默认？</b></summary>

程序目录下的 `gl_voice_config.json`。删除它即恢复默认（「已同意协议」状态也会重置）。
</details>

<details>
<summary><b>Q10 能同时开两个吗？</b></summary>

不能。软件是单实例，第二个会提示「程序已在运行」。
</details>
